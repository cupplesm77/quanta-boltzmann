# 2-D Statistical-Mechanics Relaxation and Equilibrium Sampling

This informal study program simulates random exchange of discrete energy quanta
among sites on a two-dimensional lattice. It is designed to support intuition
building about relaxation, equilibrium distributions, finite-size fluctuations,
and time-series correlation.

## Physical model

- The lattice has `M = Lx * Ly` sites.
- The conserved total number of quanta is `Q`.
- The mean occupation is `rho = Q / M`.
- One attempted update selects a donor site uniformly at random.
- If the donor is occupied, one quantum is transferred to a uniformly selected
  receiver, unless donor and receiver are the same site.
- Exchange is global, not restricted to nearest neighbors.
- One sweep equals `M` attempted updates.

For this exchange rule, the equilibrium single-site occupation distribution is
geometric:

```text
p_n = 1 / (1 + rho) * (rho / (1 + rho))^n
```

At `rho = 1`, this reduces to:

```text
p_n = 1 / 2^(n + 1)
```

## Experiments performed

The script runs two related experiments.

### 1. Independent relaxation histories

Each selected duration starts from the same pristine low-entropy state, but uses
an independent random-number seed. The program records the total-variation
distance `D(t)` after every sweep and generates plots of:

- the initial and final spatial states;
- the independent `D(t)` relaxation histories; and
- the final occupation-count distribution.

### 2. Equilibrium-fluctuation sampling

A separate lattice is equilibrated and then sampled at fixed sweep intervals.
For each sample, the program records:

- absolute sweep number;
- `D_t`, the total-variation distance from geometric equilibrium;
- occupation-bin counts `N_0`, `N_1`, ...; and
- an overflow count for occupations above `max_recorded_n`.

The raw measurements are written to `equilibrium_bin_counts.csv`. Statistical
analysis is intentionally separate from the simulation so the same expensive
run can be examined repeatedly for means, variances, Fano factors,
autocorrelation, and effective sample size.

## Requirements

- Python 3.10 or newer is recommended
- NumPy
- Matplotlib
- Numba

Install the direct dependencies with:

```bash
python -m pip install -r requirements.txt
```

## Running the simulation

```bash
python two_d_relaxation_equilibrium_sampling.py
```

The default `1000 x 1000` lattice is deliberately large and can require
substantial memory and runtime. For a quick functional check, temporarily use a
smaller lattice and shorter sweep lists.

The first call to each Numba-compiled kernel includes JIT compilation overhead.
The code warms up the relaxation kernel before timing the independent relaxation
cases. The equilibrium-sampling runtime may still include first-call compilation
for its own kernel.

## Main user-adjustable controls

```python
Lx = 1000
Ly = 1000
Q = Lx * Ly

num_sweeps = [1, 10, 20, 30, 40, 50, 100]

equilibration_sweeps = num_sweeps[-1]
sample_interval_sweeps = 10
num_equilibrium_samples = 500
max_recorded_n = 64
```

Keep the following distinctions in mind:

- `equilibration_sweeps` controls how long the transient is discarded.
- `sample_interval_sweeps` controls time separation between saved equilibrium
  observations.
- `num_equilibrium_samples` controls the length of the saved equilibrium time
  series.
- `max_recorded_n` controls CSV storage columns only. It does not truncate the
  calculation of `D(t)`.

## Reproducibility and checks

The code uses fixed seeds and verifies that:

- lattice shape and size remain unchanged;
- total quanta remain equal to `Q`;
- no site has negative occupation;
- relaxation histories contain the expected number of samples; and
- each saved equilibrium row accounts for all `M` sites, including overflow.

Changing lattice size, run order, seed values, or random-number implementation
can change the exact trajectory while preserving the expected statistical
behavior.

## Generated files

`equilibrium_bin_counts.csv` is generated by the program and ignored by the
included `.gitignore` because it can be recreated. If a particular dataset is
important for a study record, rename it descriptively and add it deliberately.
